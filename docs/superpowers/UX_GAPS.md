## Priority Quick Wins
5 changes that save the most cashier time with the least code:

1. **U03** — Enter key confirms payment in PaymentModal. ~5 lines. Saves 1 tap per sale × every sale ever. Highest ROI change in the entire codebase.
2. **U10** — SyncChip offline explanation. ~10 lines. Eliminates the most common "is this broken?" cashier anxiety moment.
3. **U01** — ProductGrid warm empty state with Back Office CTA. ~20 lines. Eliminates the #1 first-launch support question.
4. **U09** — Held cart customer name label. ~30 lines. Eliminates queue confusion with 3+ customers.
5. **U13** — Active category tab auto-scroll. ~3 lines. Fixes the invisible active state bug in horizontal scroll.
